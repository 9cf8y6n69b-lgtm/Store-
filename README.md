# NOVA STORE Bot 🌌

بوت واحد يجمع مشروعي Store و NovaSTORE: **متجر داخل التكت** + تكت متقدم + لوقات + ترحيب + تقييم + بوست + اقتراحات + XP + موسيقى + حماية، وكلها من داشبورد Nova.

## التشغيل
1. `cp .env.example .env` وعبّي `TOKEN` و `GUILD_ID` و `DASH_PASSWORD`
2. `npm install` (يثبّت better-sqlite3 للاستضافة)
3. فعّل من Developer Portal: Server Members Intent + Message Content Intent + Presence Intent
4. `npm start` ثم افتح `http://localhost:3000`

## الجديد في هذا الدمج
- **المتجر داخل التكت**: زر 🛒 *المتجر والشراء* يظهر في كل تكت ← يختار العميل المنتجات ← طريقة الدفع ← ينفتح الطلب بنفس التكت.
  الستاف: 💳 تأكيد الدفع ← ✅ تم التسليم. العميل: 🎟️ كوبون، ✖️ إلغاء. بعد التسليم يطلع تقييم.
  الإدارة من الداشبورد ← **المتجر** (منتجات، أسعار، كوبونات، معدلات الدفع، رتبة العميل، لوق الطلبات، آخر الطلبات، نقاط الستاف).
  أوامر: `/prices` `/myorders` `/topstaff`.
- **التقييم**: كرت صورة فيه صورة العضو + اسمه + عدد النجوم + كلام التقييم + صورة مرفقة (اختيارية).
  من روم التقييم (اكتب رأيك وأرفق صورة ← اختر النجوم) أو `/rate`، وبعد تسليم الطلب.
- **البوست**: أول ما عضو يسوي بوست ينرسل رسالة + صورة (النص والعنوان والتصميم من الداشبورد ← البوست).
- **الاقتراحات**: إمبيد ينرسل لروم النشر؛ العضو يكتب الاقتراح في الروم، أو من زر *اكتب اقتراحك* في لوحة (الداشبورد ← الاقتراحات ← إرسال اللوحة)، أو `/suggest`.
- **اشتراكاتي**: اكتب `/subspanel` في أي روم ← يرسل البوت لوحة بصورة مصممة وزر «اشتراكاتي». العضو يضغط الزر فيشوف اشتراكاته ووقت انتهائها، ويتحكم: 🔄 طلب تجديد (ينبّه الإدارة في روم لوق المتجر) · 🔔 تفعيل/إيقاف التذكير · ✖️ إلغاء. و`/mysubs` عرض سريع.
  كل منتج يُسلَّم من المتجر داخل التكت يتحول تلقائي لاشتراك مدته = أشهر المنتج، ويوصل العضو تذكير في الخاص قبل الانتهاء (الأيام تنضبط من الداشبورد). الداشبورد ← **الاشتراكات**: إضافة اشتراك يدوي، تمديد 30 يوم، حذف.
- **الإعلانات**: الداشبورد ← **الإعلانات** أو `/announce`: عنوان + نص + صورة NOVA STORE مصممة تلقائي + منشن (رتبة / everyone / here) + زر رابط اختياري.
- **الصور**: كل الصور (الخط، الترحيب، التكت، الرانك، اللفل أب، البوست، التقييم) مصممة على خلفية NOVA STORE البنفسجية في `assets/`.
  الخط الفاصل = `assets/line.png`، والخلفية = `assets/nova_bg.png`. تقدر تبدّلها بنفس الأسماء.

- **المجتمع** (من مشروع Store): قرعات `/giveaway` · ردود تلقائية · رتب بالأزرار · قائمة سوداء `/blacklist` — كلها من الداشبورد.
- **المتجر (إضافات)**: فواتير تلقائية عند الدفع `/invoice` · ضمان بعد التسليم `/warranty` · تقارير مبيعات وأرباح `/report` (وتلقائي أسبوعي).
- **القوانين والسياسات**: صور بتصميم NOVA STORE تتولد من نص تعدله في الداشبورد ← القوانين والسياسات، وترسلها بـ `/send-info`.

## التكت والطلب
- أزرار التكت الآن خمسة فقط، شفافة وبإيموجيات: 🔒 إغلاق · 🔔 استدعاء العضو · ✏️ تسمية · 📄 نسخة · 🛒 طلب.
- الداشبورد ← التكتات ← النصوص: خيار **رسالة التكت بدون إمبيد** (رسالة عادية بدل الإمبيد والصورة).
- **ملف البوت للمنتج**: الداشبورد ← المتجر ← المنتجات: اكتب اسم البوت وارفع الملف (حتى 25MB) بعد حفظ المنتج. بعد ما الستاف يضغط «تأكيد الدفع» يتسلّم الملف للعميل في التكت وفي الخاص، ولو كل منتجات الطلب لها ملفات يتحول الطلب «تم التسليم» تلقائي (وتشتغل الفاتورة والضمان والتقييم). تقدر توقف التسليم التلقائي من إعدادات المتجر.
- الملفات تنحفظ في `data/botfiles/`.

## الاستضافة (مدمجة)
بوتات العملاء تشتغل داخل نفس البرنامج، وكل بوت له توكن مستقل:
- بعد **تأكيد الدفع** لطلب فيه باقة أو أنظمة، يظهر للعميل في التكت زر 🤖 **أضف بوتك** ← يحط التوكن وايدي سيرفره ← يشتغل بوته فوراً بالأنظمة اللي اشتراها.
- 16 نظام جاهز (ترحيب، ردود، رتب، حماية، لوق، قرعات، اقتراحات، ليفل، تذاكر، إدارة، اقتصاد، تقديم، خط، ميوزك، ذكاء اصطناعي) والباقات: 🥉 برونزي · 🥇 ذهبي · 💎 دايموند.
- الداشبورد ← **الاستضافة**: إضافة بوت، تشغيل/إيقاف/إعادة، تعليق، تمديد، تعديل الأنظمة وإعداداتها وحالة البوت، السجل، ومفتاح **بوابة العميل** (`/portal`).
- أوامر: `/bots-panel` (روم سجل المشترين) · `/bot-plan` (تحديد الباقة والحقوق داخل التكت) · `/my-bots` · `/renew` · `/packages`.
- تنبيه تلقائي قبل انتهاء الاشتراك للعميل وللستاف، ومراقب يعيد تشغيل أي بوت يقع.
- التوكنات تنحفظ في `data/hosted_tokens.json` (خارج قاعدة البيانات)، وباقي بيانات الاستضافة في `data/hosted.sqlite`. خذ نسخة منهم مع الباك أب.
- لازم تفعّل Server Members Intent و Message Content Intent لكل بوت عميل من Developer Portal.

## ملاحظات
- بيانات المتجر تنحفظ في `data/prodb.json` (نفس نظام Nova) وتدخل في النسخ الاحتياطي التلقائي.
- لو عندك استضافة: حط `DATA_DIR` على قرص دائم.
